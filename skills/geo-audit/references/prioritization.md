# Prioritization and Evidence Labels

Do not produce a pseudo-precise overall GEO score. Prioritize findings using impact on the stated objective and evidence strength.

## Priority

| Label | Use |
|---|---|
| **BLOCKER** | An observed issue prevents access or eligibility for a target surface. |
| **HIGH IMPACT** | Strong evidence indicates a material obstacle to a relevant visibility or business outcome. |
| **OPPORTUNITY** | A reasoned improvement with plausible value, but no demonstrated current block. |
| **MONITOR** | Evidence is incomplete or the state should be watched before action. |
| **EXPERIMENTAL** | The practice or causal effect is not reliably established. |

## Evidence type

| Label | Use |
|---|---|
| **OBSERVED** | Directly inspected response, page, citation, or log evidence. |
| **MEASURED** | A defined platform or analytics metric with source and period. |
| **DOCUMENTED** | Supported by current provider or standards documentation. |
| **INFERRED** | A conclusion drawn from available evidence; state the reasoning. |
| **HEURISTIC** | A qualitative or weak proxy requiring manual review. |

Every finding should include a concise observation, evidence label, why it matters to the stated goal, and a specific action. Mark unavailable evidence explicitly; never turn a heuristic into a measured fact.
