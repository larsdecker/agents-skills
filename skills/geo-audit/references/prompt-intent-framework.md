# Prompt and Intent Framework

Build a representative question set from the target audience, product, market, and research evidence. This is a working framework, not a claim that every provider uses the same intent taxonomy.

| Intent | Example question |
|---|---|
| Informational | What are duplicate files? |
| Learn and solve | How can I remove duplicate photos safely? |
| Comparison | How does Duplicate Cleaner compare with Abelssoft? |
| Commercial | Which duplicate file finder works on Windows 11? |
| Research | Which tools can identify visually similar photos accurately? |
| Navigational | Where can I download Abelssoft's duplicate file finder? |
| Planning | How should I clean up a 2 TB photo library? |

For each topic, record the audience, market/language, user question, intent, expected answer type, and any meaningful constraints (for example, OS version, budget, safety, or data volume). Include informational and commercial questions where relevant. Do not invent demand or represent illustrative prompts as measured search volume.
